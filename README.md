# inflation-forecasting-peru-random-forest

La investigación utiliza información histórica de expectativas inflacionarias provenientes de analistas económicos, entidades del sistema financiero y empresas no financieras, junto con datos de inflación observada. A partir de ello, se desarrolla un proceso de limpieza, transformación y modelado de datos orientado a la construcción de modelos predictivos basados en técnicas de aprendizaje automático y análisis de series temporales. Asimismo, se comparan los resultados obtenidos entre distintos grupos de agentes económicos con el objetivo de identificar cuáles presentan una mayor capacidad para anticipar el comportamiento futuro de la inflación.
Para la evaluación del desempeño predictivo se emplean métricas estadísticas como el Error Absoluto Medio (MAE) y la Raíz del Error Cuadrático Medio (RMSE), permitiendo contrastar la precisión de los modelos desarrollados. Los resultados esperados buscan evidenciar el potencial de la técnica de Random Forest como herramienta complementaria para el análisis macroeconómico y el pronóstico de inflación en economías emergentes.
